# 文章 BBCode 渲染

文章详情、章节阅读器和评论共用 `BbCode`（解析）、`BbCodeRendering`（原生样式和交互）、`BbCodeText`（富文本分段与表格测量）。参考当前 `ft-front/app/utils/bbcode-pm-codec.ts`、`bbcode-pm-dom.ts`、`bbcode-shared.ts` 和 `ft-go/pkg/bb/bb.go`；有差异时优先采用当前前端语义。

支持：

- 粗体、斜体、下划线、删除线、上下标；嵌套前景色、背景色、字体、相对字号。`size=larger/smaller` 累加，最多 ±8 级。
- 标题、换行、分隔线、多行和嵌套引用、左右及居中对齐、首行缩进。兼容迁移文章使用的 `pt` 缩进。
- 无序、有序和嵌套列表，支持省略 `[/*]`。
- 图片及尺寸/替代文本，行内 Ftemoji、链接、提及和话题搜索。
- BBCode 和 Markdown 表格，包括表头、单元格文字样式及对齐。
- 剧透和折叠内容保留原文，点击在可滚动对话框中查看；揭开前不渲染其中的图片。
- 作品、章节、评论、频道和用户引用显示为可点击文字。章节和评论通过当前 API 查询所属作品后跳转，保留描述及失败提示。
- `[code]` 保留代码原文、换行和缩进；只有 `[markdown]` 启用 CommonMark，并支持表格和删除线。原始 HTML 作为文字显示。

阅读器先渲染完整章节，再按富文本测量和切页。`ReaderPagination` 使用与正文 TextView 一致的字号转换、字体、中文回退字体行高和行距；每个分页片段都会重新测量，溢出的行继续放到下一页。段落跨页时不重复首行缩进，屏幕可用区域或异步图片高度变化时重新分页并保持阅读位置。分页和滚动分段保留 span，不再截断 BBCode/Markdown 源码，也不再给代码和列表强加全角缩进。表情保留在句中，独立图片继续使用阅读器图片页。

当前原生显示与网页的差异：

- 折叠/剧透使用对话框展开；引用使用文字链接，不预加载网页卡片。
- `colspan/rowspan` 转为等宽网格，合并单元格的内容保留在起始格，不绘制跨格边框。超过 8 列的表格按单元格顺序显示段落，避免窄屏裁掉内容；超出一页高度的单元格在左右翻页模式下使用可纵向滚动的独立页；表格内链接使用 Markwon 的静态单元格呈现。
- `justify` 保留正文并按起始边对齐；字体取决于设备可用字体，无法保证网页字体一致。
- Markdown 的数学公式、脚注、定义列表等网站扩展暂不实现；`handbook` 显示未内嵌手册的提示，与前端的不可用占位保持一致。

安全和容错：正文转义后输出 HTML；不完整/未知标签保留可见文字；代码不扫描图片；链接和图片仅接受 HTTP(S)、站内绝对路径，链接另支持锚点，迁移图片另允许限定格式的 raster base64 data URL。解析嵌套深度限制为 128，避免异常输入耗尽调用栈。

测试：`BbCodeTest` 覆盖语法、转义、嵌套、恶意 URL、隐藏内容及超长参数；`BbCodeRenderingTest` 使用 Robolectric 的 Android 34 原生绘图验证实际 span、表格测量和分段。`app/src/test/resources/bbcode-corpus.fixture.json` 来自 `ft-front/app/utils/bbcode-corpus.fixture.json`，为前端已有的 20 条匿名化文章样例。

## 作品 71323 分页回归

[作品 71323](https://fimtale.dev/work/71323) 的前言和第一章使用大量 `[indent=28.0pt]` 段落。旧分页未启用回退字体行高，且按整章行号切出的片段未经再次测量；回归案例中 560px 的页面实际排版约 630px，跨页重复首行缩进还会增加换行。

`ReaderPaginationTest` 通过 Activity 分页入口及实际 TextView 排版检查每页高度，并逐字拼回原文，验证没有漏字或重复。`reader-71323.fixture.json` 保留该作品前言/第一章的 BBCode、标点、段落长度和空行，将汉字正文匿名化；测试覆盖 16/20/28sp、1.0/1.4/1.8 行距、竖屏/横屏尺寸、系统大字体、嵌套样式，以及单行超高内容的可滚动回退。测试无需联网。

## 编辑器

正文编辑器保留原始 `Editable`，仅用 span 绘制格式，选区、输入法组合文本和保存内容不会被渲染改写。颜色（包括 RGB/HSL 和 CSS 短十六进制）、相对字号、字体和 `pt/em/px/%` 缩进与阅读器共用规则；取消额外强加的两字缩进，避免作者的缩进、代码和居中内容被重复偏移。

列表、表格、Markdown、折叠、实体引用和分隔线在光标离开后显示为预览块；提及和话题显示行内标签。独立源码段落中的 `[br]` 显示实际换行。点击或移动光标进入预览块，会还原该块全部源码，方便修改标签、表格结构或 Markdown；“源码”按钮可显示全文标签。复杂块与其他正文共用同一源码行且跨越多行时保留可编辑样式，避免隐藏旁边的正文。

顶部按钮在已有作品或章节显示“保存”，新建时显示“发表”，与元数据菜单中的提交按钮共用流程。作品验证码使用原生 Material 3 弹窗，标题、加载指示、提示文字、取消和切换按钮均为原生控件；WebView 仅承载服务商验证组件。默认 Cloudflare；遇到错误或超时可随机切换本轮未尝试的服务，全部尝试后开始下一轮，并记住上次成功的服务。元数据菜单内显示处理状态和错误提示。正文内的 BBCode 渲染保留，表格合并单元格、两端对齐和高级 Markdown 的限制与阅读器一致。

`BbCodeSyntaxTest` 覆盖带引号的属性、隐式列表项、未完成输入和原文偏移；`BbCodeEditTextRenderingTest` 使用 Android 原生排版验证复杂块、源码切换、选区/输入法 span 保留、无文本变更回调，以及完整预览。
