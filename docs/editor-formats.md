# 编辑器插入格式

参考 `ft-front/app/components/BBCodeEditorChrome.vue`、`ft-front/app/utils/bbcode-pm-codec.ts` 与 `ft-go/web/static/component/BBCodeEditor.vue`。正文仍保存原始 BBCode，文章序言与章节使用同一套插入命令。

底部工具栏保留粗体、斜体、引用、黑条、表情、本地图片和源码切换；按钮为 48dp 点击区域、20dp MDI 图标，可横向滑动。“更多格式”图标固定在右侧，打开原生 MD3 底部面板。

| 分组 | 格式 |
| --- | --- |
| 文字 | 粗体、斜体、下划线、删除线、上下标、增大/减小字号、文字颜色、文字背景、黑条 |
| 段落 | H1–H6、左/中/右/两端对齐、首行缩进、引用、有序/无序列表 |
| 内容 | 链接、图片链接、提及用户、话题标签、表格、折叠区、代码块、Markdown、引用卡片、分隔线 |

链接、颜色、图片、表格、折叠区、话题与引用卡片提供参数表单。图片支持可选宽高和说明；表格支持 1–20 行、1–10 列及可选表头；引用类型为作品(1)、章节(3)、评论(4)、频道(5)、用户(7)。提及通过完整用户名查询 `user/get_user_page_header`，使用返回的真实 ID 生成 `[mention=ID]用户名[/mention]`，不会向用户发送消息。

选中内容会进入对应格式；未选中内容时，文字格式将光标放在标签内，表格放在首个单元格，列表放在首项。块格式会按需在前后补换行，避免与相邻段落粘连。参数表单保存原选择范围，旋转和暂离应用不会丢失表单；正文版本变化后停止使用旧插入范围。一个操作只产生一次文本替换。

引用和标签文字中的方括号使用网站的 `&#91;` / `&#93;` 转义；代码与 Markdown 内部按原文保留，并转义会提前闭合当前块的标签。参数中的网址、颜色、尺寸和 ID 先验证再插入，错误和取消不会改动正文。

新增 `BbCodeInsertionTest`、`EditorFormatDialogTest` 验证生成代码、源码范围、参数校验、旋转和表单恢复；原有解析和编辑渲染测试验证格式兼容。设备测试通过本地接口模拟验证实际编辑器的面板、嵌套格式、链接及提及，不发表真实文章。
